Tools I built and run

Two sets of tools. The first is what my sales team at a dietary-supplement contract manufacturer uses every day for quoting, margin tracking and customer management, rebuilt here as working demos on synthetic data. The second is a set of New Zealand pharmaceutical market tools that run live on public PHARMAC, PBS, Medsafe and FDA data.

How the demos work

1 · Real front endThe same HTML and JavaScript the team uses, with company names removed.
2 · Real back endThe Apps Script server code runs unchanged in your browser.
3 · EmulatorsApps Script tools: a stand-in for Sheets, Properties, UrlFetch and google.script.run. CRM: the real Worker runs in your browser with KV, a SQLite database for D1 and a signed sign-in token for Cloudflare Access.
4 · Synthetic dataInvented ingredients, prices, clients and sales. Your changes stay in your browser.

No server and no sign-in. AI features return fixed demo answers instead of calling Gemini. Use the Reset button on any page to restore the original demo data.
