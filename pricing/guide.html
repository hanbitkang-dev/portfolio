R&D Tool 개요

R&D Search & AI Recommend Tool

기존 제품 데이터베이스에서 제품과 원료 구성을 검색하고, AI(Gemini)로 신규 제품 원료를 추천받거나 기존 제품 업그레이드 방향을 분석합니다.

페이지: ?page=search AI 추천: ?page=recommend
Tool 1 — 제품 검색 (R&D Search) ?page=search
OB(벌크 완제품) 데이터베이스에서 키워드·제형으로 제품을 찾고, 해당 제품의 원료 구성(BOM)을 조회합니다.
1
제형 필터 선택
페이지 상단에서 제형을 먼저 선택합니다 — 전체 / SGC / Hard Cap / Tablet / Powder / Liquid / Sachet / Blister. 제형을 선택하지 않으면 전체 DB에서 검색합니다.
2
키워드 입력
제품명, OB코드, 원료명, 고객사명 등 자유롭게 입력하세요. 한글·영문 모두 검색 가능합니다. 예: OB-2301, Fish Oil, Southern Light
3
검색 결과에서 제품 선택
결과 목록에서 제품을 클릭하면 해당 제품의 원료 구성(BOM)이 오른쪽 패널에 펼쳐집니다. 각 원료의 mg/ea, 원료 코드, 통화 정보를 확인할 수 있습니다.
4
Pricing Tool로 이동
BOM 패널에서 "이 제품으로 견적 만들기" 버튼을 클릭하면 Pricing Calculator로 이동하면서 원료 구성이 자동으로 채워집니다.
활용 팁: 경쟁 제품이나 레퍼런스 제품의 BOM을 먼저 확인한 뒤 Pricing Tool로 넘어가면, STEP 3 원료 입력을 처음부터 하지 않아도 됩니다.
Tool 2 — AI 원료 추천 (AI Recommend) ?page=recommend
Google Gemini AI가 요구사항에 맞는 원료(OR)와 부자재(OP)를 추천하거나, 기존 제품의 업그레이드 방향을 제안합니다.
신규 제품 원료 추천
1
제품 요구사항 입력
목표 효능, 제형(SGC·Tablet 등), 타깃 소비자, 용량 기준, 예산 등 자유롭게 입력합니다.
2
AI 추천 확인
Gemini가 OR코드 기반 원료 리스트와 각 원료의 추천 이유, 예상 mg/ea를 반환합니다.
3
Pricing Tool로 이동
추천 원료를 선택하면 Pricing Calculator STEP 3에 자동으로 채워집니다.
기존 제품 업그레이드 분석
1
기존 제품 BOM 불러오기
OB코드를 입력하거나 검색으로 제품을 선택해 현재 BOM을 로드합니다.
2
업그레이드 방향 지정
비용 절감 / 효능 강화 / 트렌드 반영 등 개선 방향을 선택하고 추가 요구사항을 입력합니다.
3
대체/추가 원료 제안 확인
Gemini가 현재 BOM을 분석하여 대체 원료나 추가 원료를 이유와 함께 제안합니다.
주의: AI 추천은 OR/OP 데이터베이스 기반 참고 자료입니다. 최종 원료 선정 전 R&D 담당자의 검토가 필요합니다.
Pricing Calculator 개요

Sales Pricing Calculator (6 STEP)

원료·포장재·가공비를 단계별로 입력해 제품별 공급 단가를 계산하고, 견적을 저장·관리하는 핵심 툴입니다. 이전 공급가와 자동 비교해 가격 변동을 즉시 확인할 수 있습니다.

페이지: ?page=pricing 견적 저장: Google Sheets (Pricing_History) 환율: 매일 오전 9시 자동 업데이트
6단계 견적 흐름 (STEP 1 → 6)
위에서 아래로 순서대로 입력하면 STEP 6에서 최종 단가와 마진 시뮬레이션이 자동으로 계산됩니다.
Step항목주요 기능입력 방법
STEP 1 기본 정보 제품명, 총 Unit 수, 정/캡슐 per bottle 입력. PFS 파일 업로드 또는 OF/OB/OC 코드로 BOM 자동완성. PFS 업로드 또는 코드 입력 후 "BOM 불러오기"
STEP 2 제품 유형 SGC / Hard Cap / Tablet / Powder / Liquid / Sachet / Blister 중 선택. SGC는 기계 사이즈(12/20/24 Oblong), Tablet은 무게 구간을 추가 선택. 버튼 클릭 → Processing 단가표 자동 연결
STEP 3 Raw Material OR코드로 원료 검색, mg/ea 입력, 통화·Incoterms·운송 방법 선택. Final Price(NZD/kg)와 소계가 실시간 자동 계산됨. Loss Rate 설정. 검색창에 OR코드 또는 원료명 입력
STEP 4 Packages + Processing OP코드로 포장재 검색, packaging_type에 따라 Processing 항목 자동 활성화. 수량 구간별 단가 자동 적용. 가공비 항목 수동 추가 가능. OP 검색 → Processing 행 활성화 확인
STEP 5 Admin & Others Admin 고정비(NZD 300), Test 비용, 기타 항목(동적 추가). 환율 정보 표시. Test 비용과 기타 항목 직접 입력
STEP 6 결과 & 견적 저장 Cost Breakdown, Unit Cost 계산. 5~25% 마진 시뮬레이션. 이전 공급가 자동 비교. 견적 저장 및 PDF 출력. "견적 저장" → Draft 상태로 저장
주요 기능 상세
PFS 자동완성
PFS(Product Formula Sheet) 파일을 업로드하면 원료 목록이 STEP 3에 자동 채워집니다. OR코드 매칭으로 단가·통화 정보도 함께 불러옵니다.
BOM 코드 자동완성
OF/OB/OC 코드 입력 → BOM 시트에서 원료(STEP 3)와 부자재(STEP 4)를 한번에 불러옵니다. 코드 1개로 전체 원료 구성이 채워집니다.
환율 자동 변환
원료 통화(USD·KRW·AUD)를 NZD로 자동 변환. 환율은 매일 오전 9시 업데이트되며, 화면 우상단에 현재 환율이 표시됩니다.
마진 시뮬레이션
STEP 6에서 5%·10%·15%·20%·25% 마진별 공급가를 동시에 확인. 이전 공급가(supply history)와 자동 비교해 가격 변동폭을 즉시 파악.
견적 상태 관리
견적 저장 후 상태 변경 가능: Draft → Reviewed → Approved. 견적 목록에서 상태별 필터링, 기존 견적 불러오기 및 수정.
PDF 견적서 출력
STEP 6 "📄 견적서 저장" 버튼 클릭 → 브라우저 인쇄 기능으로 A4 PDF 저장. 견적 목록의 각 행에서도 PDF 출력 가능.
계산 기준 요약
원료 Final Priceunit_price → 환율 변환 + 통관비(USD/kg) + 운송비(USD/kg) → NZD/kg. Incoterms 조건에 따라 운송비 가산 여부 결정.
Loss Rate원료 합계 × (1 + Loss Rate). 기본 8%, 견적 내에서 수동 변경 가능.
포장재 Final Priceunit_price → 환율 변환만 (통관비·운송비 없음). NZD/ea.
Processing 단가총 Units 기준 구간별 단가표 조회. 수식 유형: encap(캡슐 lots), perPk(병/sachet 수), blending(원료 무게 배치), blistering(blister 장 수).
Unit Cost(원료총비 + 포장재총비 + 가공비총비 + Admin + Test + Others) ÷ 총 Units.
공급가 계산Unit Cost ÷ (1 − Margin%). 예: Unit Cost NZD 5, Margin 20% → 공급가 NZD 6.25.
Settings 메뉴 활용: 사이드바 하단 Settings에서 통관비·운송비·기본 Loss Rate·Admin 비용, 그리고 Processing 단가 구간표를 수정할 수 있습니다. 수정하면 Google Sheets에 즉시 저장되며 모든 신규 견적에 적용됩니다.
GM Dashboard 개요

GM Analysis Dashboard

공장원가(Cost Master)와 실제 매출(Sales Order) 데이터를 연결해 제품별·회사별 GM%(Gross Margin)를 자동 집계합니다. 어떤 제품이 얼마나 남는지를 한눈에 파악할 수 있습니다.

페이지: ?page=gm 데이터 갱신: Python 스크립트 로컬 실행 후 업로드 비밀번호 보호 접근
데이터 업로드 파이프라인
GM 대시보드 데이터는 로컬 PC에서 Python 스크립트를 실행해 Google Sheets로 업로드합니다.
1
공장원가 Excel 준비
gm_analysis/data/cost_files/ 폴더에 클라이언트별 공장원가 Excel 파일을 저장합니다. 파일명에 클라이언트명 약자 포함 (예: RS_원료_Pricing.xlsx → Southern Light).
2
Sales 데이터 준비
gm_analysis/data/sales/Sales_statistics.xlsx를 최신 파일로 교체합니다.
3
공장원가 파싱
PowerShell에서 python parse_cost_files.py 실행 → output/cost_master.csv 자동 생성. 6개사 공장원가 Excel을 정규화해 OF코드·OB코드·unit_cost 등을 추출합니다.
4
GAS로 전송
python upload_to_gas.py 실행 → Cost Master + Sales 데이터를 GAS 웹앱(doPost)으로 전송. GM_CostMaster · GM_Sales 시트에 전량 갱신(덮어쓰기).
5
대시보드 확인
업로드 완료 후 GM Dashboard (?page=gm)를 새로고침하면 최신 데이터로 집계 결과가 표시됩니다.
업로드는 전량 덮어쓰기 방식입니다. 부분 갱신이 불가능하므로, 항상 전체 공장원가 파일 + 전체 Sales 데이터를 함께 업로드해야 합니다.
대시보드 기능
요약 카드 4종
Total Revenue · Total Factory Cost · Overall GM% · Coverage(매칭 제품·회사 수). 페이지 상단에 항상 표시.
연도 탭
2025+2026 합산 / 2025 / 2026 탭 전환으로 연도별 비교. 기본은 합산 뷰.
제품별 GM% 뷰
OF코드·제품명·고객사·공장원가·공급가·GM%·누적 Revenue·총 수량. 검색·고객사 필터·GM% 구간 필터(15% 미만 / 15~25% / 25% 이상) 지원.
회사별 GM% 뷰
고객사별 제품 수·누적 Revenue·누적 원가·GM(NZD)·Blended GM%. Revenue 내림차순 기본 정렬, 헤더 클릭으로 정렬 변경.
GM% 색상 신호
■ 초록 양호(25% 이상) · ■ 주황 주의(15~25%) · ■ 빨강 위험(15% 미만). 한눈에 리스크 파악.
접근 제어
비밀번호 없이, 회사 Google 계정(@example.com)으로 로그인한 접근 명단의 사람만 열립니다 (v1.32~). 명단 변경: ScriptProperties ALLOWED_USERS (쉼표로 구분한 이메일) — 재배포 없이 바로 적용.
