R&D Tool overview

R&D Search & AI Recommend Tool

Search products and their ingredients in the existing product database, get AI (Gemini) ingredient suggestions for new products, or analyse how to upgrade an existing product.

Pages: ?page=search AI suggestions: ?page=recommend
Tool 1 — Product search (R&D Search) ?page=search
Find products in the OB (bulk) database by keyword and dosage form, and view each product’s ingredient list (BOM).
1
Choose a dosage form
Pick the dosage form at the top first — All / SGC / Hard Cap / Tablet / Powder / Liquid / Sachet / Blister. With no form selected, the whole DB is searched.
2
Enter a keyword
Product name, OB code, ingredient name, client name — anything. E.g. OB-2301, Fish Oil, Southern Light
3
Pick a product from the results
Click a product in the results to open its ingredient list (BOM)in the right panel, with mg/ea, ingredient code and currency for each ingredient.
4
Go to the Pricing Tool
In the BOM panel, click "Quote this product" to open the Pricing Calculator with the ingredients filled in.
Tip: Check a competitor or reference product’s BOM first, then move to the Pricing Tool, so you don’t have to enter STEP 3 ingredients from scratch.
Tool 2 — AI ingredient suggestions (AI Recommend) ?page=recommend
Google Gemini suggests ingredients (OR) and packaging (OP) for a brief, or proposes how to upgrade an existing product.
Ingredients for a new product
1
Enter the product brief
Target benefit, dosage form (SGC, Tablet, etc.), target consumer, dose, budget — write freely.
2
Review the AI suggestions
Gemini returns a list of ingredients by OR code, with the reason for each and an expected mg/ea.
3
Go to the Pricing Tool
Selected ingredients are filled into Pricing Calculator STEP 3.
Upgrade analysis for an existing product
1
Load an existing product’s BOM
Enter an OB code or pick a product from search to load its current BOM.
2
Choose the upgrade direction
Pick a direction (lower cost / stronger efficacy / follow trends, etc.) and add any other requirements.
3
Review replacement/added ingredients
Gemini analyses the current BOM and suggests replacement or added ingredients with reasons.
Note: AI suggestions are a reference based on the OR/OP database. An R&D owner must review them before choosing final ingredients.
Pricing Calculator overview

Sales Pricing Calculator (6 STEP)

The core tool for calculating the supply price of each product step by step from ingredients, packaging and processing, and for saving and managing quotes. It compares with previous supply prices automatically, so price changes show at once.

Pages: ?page=pricing Quotes saved in: Google Sheets (Pricing_History) FX: updated automatically every day at 9 am
6-step quote flow (STEP 1 → 6)
Fill in from top to bottom; STEP 6 calculates the final price and margin simulation automatically.
StepItemMain featuresHow to enter
STEP 1 Basics Product name, total units, tablets/capsules per bottle. Upload a PFS file or enter an OF/OB/OC code to fill the BOM. PFS upload or enter a code, then "Load BOM"
STEP 2 Product type Choose SGC / Hard Cap / Tablet / Powder / Liquid / Sachet / Blister. SGC also needs the machine size (12/20/24 Oblong), Tablet the weight band. Click a button → linked to the Processing price table
STEP 3 Raw Material Search ingredients by OR code, enter mg/ea, choose currency, Incoterms and freight. Final Price (NZD/kg) and subtotal update live. Set the loss rate. Type an OR code or ingredient name in the search box
STEP 4 Packages + Processing Search packaging by OP code; Processing items switch on by packaging_type. Tier prices by quantity apply automatically. Processing items can be added by hand. Search OP → check the Processing rows are on
STEP 5 Admin & Others Admin fixed cost (NZD 300), Test cost, other items (add as needed). FX shown. Enter Test cost and other items directly
STEP 6 Results & saving the quote Cost Breakdown, Unit Cost. Margin simulation 5–25%. Compared with previous supply prices automatically. Save quotes and print PDF. "Save quote" → saved as Draft
Main features in detail
PFS autocomplete
Upload a PFS (Product Formula Sheet) and the ingredient list fills STEP 3. Prices and currencies come in too, matched by OR code.
BOM code autocomplete
Enter an OF/OB/OC code → ingredients (STEP 3) and packaging (STEP 4) load from the BOM sheet at once. One code fills the whole formula.
Automatic FX conversion
Ingredient currencies (USD · KRW · AUD) converted to NZD. FX updates daily at 9 am; current rates show at the top right.
Margin simulation
STEP 6 shows supply prices at 5% · 10% · 15% · 20% · 25% margin side by side, and compares with previous supply prices (supply history) to show the change at once.
Quote status
After saving, status can be changed: Draft → Reviewed → Approved. Filter the quote list by status, load and edit existing quotes.
PDF quote
STEP 6 "📄 Save quote PDF" button → saved as an A4 PDF through the browser’s print. Each row in the quote list can also print a PDF.
Calculation basis
Ingredient Final Priceunit_price → FX conversion + customs (USD/kg) + freight (USD/kg) → NZD/kg. Incoterms decide whether freight is added.
Loss RateIngredient total × (1 + loss rate). Default 8%, can be changed within a quote.
Packaging Final Priceunit_price → FX conversion only (no customs or freight). NZD/ea.
Processing priceTier price table by total units. Formula types: encap (capsule lots), perPk (bottles/sachets), blending (ingredient weight per batch), blistering (blister sheets).
Unit Cost(ingredients + packaging + processing + Admin + Test + Others) ÷ total units.
Supply priceUnit Cost ÷ (1 − Margin%). E.g. Unit Cost NZD 5, margin 20% → supply price NZD 6.25.
Using Settings: Settings at the bottom of the sidebar lets you change customs, freight, default loss rate, Admin cost and the Processing tier tables. Changes save to Google Sheets at once and apply to all new quotes.
GM Dashboard overview

GM Analysis Dashboard

Joins factory cost (Cost Master) with actual sales (Sales Order) data and adds up GM% (gross margin) by product and by company, so you can see what each product earns at a glance.

Pages: ?page=gm Data refresh: run a Python script locally, then upload Password-protected access
Data upload pipeline
GM dashboard data is uploaded to Google Sheets by running a Python script on a local PC.
1
Prepare the factory cost Excel files
gm_analysis/data/cost_files/ Save each client’s factory cost Excel file in the folder. Include the client abbreviation in the file name (e.g. RS_Pricing.xlsx → Southern Light).
2
Prepare the sales data
gm_analysis/data/sales/Sales_statistics.xlsxReplace it with the latest file.
3
Parse factory costs
In PowerShell, run python parse_cost_files.py → output/cost_master.csv is created. Normalises six companies’ factory cost Excel files and extracts OF code, OB code, unit_cost, etc.
4
Send to GAS
python upload_to_gas.py Run → Cost Master + Sales data are sent to the GAS web app (doPost). GM_CostMaster and GM_Sales sheets are fully replaced (overwrite).
5
Check the dashboard
After the upload, GM Dashboard (?page=gm)refresh it to see results from the latest data.
Uploads overwrite everything. Partial updates are not possible, so always upload the full set of factory cost files and the full sales data together.
Dashboard features
Four summary cards
Total Revenue · Total Factory Cost · Overall GM% · Coverage(matched products and companies). Always at the top of the page.
Year tabs
2025+2026 combined / 2025 / 2026 Switch tabs to compare years. Combined view by default.
GM% by product
OF code, product name, client, factory cost, supply price, GM%, cumulative revenue, total quantity. Search, client filter and GM% band filter (under 15% / 15–25% / 25% or more).
GM% by company
Per client: products, cumulative revenue, cumulative cost, GM (NZD), blended GM%. Sorted by revenue (high to low) by default; click a header to change.
GM% colours
■ Green healthy (25% or more) · ■ Orange watch (15–25%) · ■ Red at risk (under 15%). Risks at a glance.
Access control
No password: opens only for people on the access listsigned in with the company Google account (@example.com) (v1.32~). Change the list in ScriptProperties ALLOWED_USERS (comma-separated emails) — applies straight away, no redeploy.
